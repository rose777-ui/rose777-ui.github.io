# Rokia Jannat — AI/ML & Software Developer Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. No framework, build step, or package installation is required.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For local development, you can optionally use VS Code Live Server.

## Included
- Responsive dark interface with a subtle animated AI/graph hero.
- Smooth, cloud-like scroll reveals: content cards fade in, sharpen from a soft blur, and gently rise into place.
- Scroll progress, active navigation, mobile menu, and reduced-motion accessibility.
- Featured STAG-RAG project and selected academic/software projects.
- LeetCode profile link: https://leetcode.com/u/rose_77/
- Skill constellation around the LeetCode profile. Problem totals are not hard-coded because they change over time.

## Update your content
Edit `index.html` to change text, projects, links, or contact details. Edit `styles.css` for visual styling and `script.js` for interactions.

## Before publishing
Double-check contact details, public project links, and every reported performance metric. Keep project status (completed, ongoing, research-stage) accurate.
